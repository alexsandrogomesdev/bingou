# Bingou - Uma aplicação web para gerar cartelas de bingo com marcação em tempo real.

> ⚠️ **Nota:** Este projeto é uma ferramenta utilitária de marcação e simulação visual de cartelas. Não se trata de uma plataforma de apostas ou jogos de azar com premiação.

---

## 🚀 Tecnologias

- **Frontend:** React, TypeScript, Vite, CSS Modules
- **Backend:** NGINX, Docker, Node.js, TypeScript, PostgreSQL
- **Deploy Frontend:** Cloudflare Pages

---

## 💡 Modelo do App

- **Plano Gratuito:** Geração e marcação de até 50 cartelas por evento/sorteio.
- **Plano Pro (Pago):** Liberação de limites expandidos (mais de 50 cartelas).
